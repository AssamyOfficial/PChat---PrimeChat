# PrimeChat 1.3.0

**Современная система чата для Paper:** каналы, личные сообщения, упоминания, AFK, SocialSpy, CommandSpy, управление командами и гибкая настройка через YAML.

PrimeChat рассчитан на серверы, которым нужна полноценная система общения без необходимости собирать десятки небольших плагинов.

## Возможности

### Каналы

- Локальный чат с настраиваемым радиусом.
- Глобальный чат через триггер `!`.
- Неограниченное количество собственных каналов.
- Командные каналы с aliases и отдельными permissions.
- Автоматический Tab Completion для командных каналов.
- Админ-чат и Donate-чат.
- Настраиваемые форматы, HEX и MiniMessage.

### Чат и взаимодействие

- Цветной и форматированный чат с отдельным permission.
- Hover и кликабельные ники.
- Упоминания через `@ник`.
- Несколько упоминаний в одном сообщении.
- Уведомление об упоминании только если игрок реально получил сообщение.
- Настраиваемый звук при упоминании.
- Сообщения для офлайн-игроков и неизвестных ников.
- Защита от уведомления при самоупоминании.
- Сообщение «Вас никто не услышал» с отдельной настройкой для каналов.

### Личные сообщения

- `/msg`, `/m`, `/message`.
- Многострочный формат личных сообщений.
- `/r` и `/reply` для быстрого ответа.
- Звук входящего сообщения.
- Кликабельный ответ через `/r`.
- Уведомление отправителю, если адресат находится в AFK.
- Получение сообщения не снимает AFK.

### Администрирование

- `/ss` / `/socialspy` — просмотр личных сообщений.
- `/cs` / `/commandspy` — просмотр команд игроков.
- `/cc` / `/clearchat` — очистка чата.
- `/afk` — управление AFK.
- `/chat` / `/ch` — включение и отключение чата.
- Whitelist команд.
- Blacklist команд.
- Задержки выполнения команд.
- Уменьшение задержки через permission.
- Полный обход задержки через permission.
- Обход whitelist/blacklist через permission.
- Перезагрузка конфигурации без перезапуска сервера.

## Установка

1. Скачайте `PrimeChat-1.3.0.jar`.
2. Поместите JAR в папку `plugins/`.
3. Запустите или перезапустите сервер.
4. Настройте `config.yml` и `command.yml`.
5. Примените изменения через `/pc reload`.

После запуска PrimeChat использует два основных файла:

```text
plugins/PrimeChat/config.yml
plugins/PrimeChat/command.yml
```

`config.yml` предназначен для основных функций плагина, каналов и общих настроек.

`command.yml` предназначен для команд, их сообщений, форматов, permissions и контроля выполнения.

# MiniMessage и HEX

PrimeChat использует форматирование MiniMessage.

### HEX

```yaml
format: "<#00E5FF>%player%</#00E5FF> <gray>»</gray> <white>%message%</white>"
```

### Градиент

```yaml
format: "<gradient:#00E5FF:#7C4DFF>%player%</gradient> <gray>»</gray> <white>%message%</white>"
```

### Пример собственного формата

```yaml
format: "<gradient:#00E5FF:#00FF88>◆ %player%</gradient> <dark_gray>»</dark_gray> <gray>%message%</gray>"
```

Основные placeholders PrimeChat:

| Placeholder | Значение |
|---|---|
| `%player%` | Ник игрока |
| `%displayname%` | Display Name игрока |
| `%display_name%` | Альтернативная запись Display Name |
| `%message%` | Сообщение |

При установленном PlaceholderAPI дополнительно доступны его placeholders.

# Каналы

Каналы создаются в `config.yml` в разделе `channels`.

## Локальный чат

```yaml
local:
  enabled: true
  mode: "local"
  radius: 100
  format: "<#00E5FF>Ⓛ</#00E5FF> <#00E5FF>%player%</#00E5FF> <gray>»</gray> <white>%message%</white>"
```

Игроки получают сообщение только если находятся в пределах указанного радиуса и соответствуют условиям канала.

## Глобальный чат

```yaml
global:
  enabled: true
  mode: "global"
  trigger: "!"
  format: "<#7C4DFF>Ⓖ</#7C4DFF> <#7C4DFF>%player%</#7C4DFF> <gray>»</gray> <white>%message%</white>"
```

Пример:

```text
!Всем привет!
```

Сообщение будет отправлено через глобальный канал.

## Пользовательский командный канал

```yaml
vip:
  enabled: true
  mode: "command"
  command: "vip"
  aliases:
    - "v"
  permission: "primechat.vip"
  format: "<#FFD54F>◆ VIP</#FFD54F> <#00E5FF>%player%</#00E5FF> <gray>»</gray> <white>%message%</white>"
```

После `/pc reload` канал автоматически регистрирует свою команду и aliases. Tab Completion для созданных командных каналов также формируется автоматически.

## Стандартные каналы

| Канал | Использование | Permission |
|---|---|---|
| Local | обычный чат | нет |
| Global | `!сообщение` | нет |
| Admin | `/ac`, `/adminchat` | `primechat.admin` |
| Donate | `/dc`, `/donatechat` | `primechat.donate` |

Staff Chat в PrimeChat 1.3.0 не поставляется. При необходимости сервер может создать его самостоятельно как обычный командный канал.

# Личные сообщения

## Отправка

```text
/msg <игрок> <сообщение>
/m <игрок> <сообщение>
/message <игрок> <сообщение>
```

Пример:

```text
/msg Steve Привет, как дела?
```

## Ответ

```text
/r <сообщение>
/reply <сообщение>
```

После получения ЛС игрок может ответить без повторного указания ника.

## Многострочный формат

Формат ЛС настраивается в `command.yml`. Например:

```yaml
format:
  incoming:
    - "<#00E5FF>◆ ЛС</#00E5FF> <gray>← %sender%</gray>"
    - "<gray>%message%</gray>"
```

Таким образом имя отправителя и текст сообщения могут находиться на разных строках.

Входящее сообщение может сопровождаться звуком, а оформление ответа и другие параметры настраиваются в `command.yml`.

Если адресат находится в AFK, отправитель получает соответствующее уведомление. Получение ЛС само по себе не снимает AFK.

# Упоминания

Игроков можно упоминать через `@`:

```text
@Assamy_ Привет!
```

Можно упомянуть сразу нескольких игроков:

```text
@Assamy_ @Assamy_2 Привет!
```

Поддерживаются ники с буквами, цифрами и `_`.

Онлайн-игрок получает уведомление только если реально получил исходное сообщение. Поэтому упоминание игрока вне радиуса локального чата не создаёт лишнее уведомление.

Самоупоминание не отправляет уведомление самому автору.

Если игрок офлайн, отправителю показывается сообщение из настройки офлайн-упоминания. Если сервер не знает такого игрока, используется сообщение `not-found`.

## Звук упоминания

Звук можно включать и выключать в `config.yml`:

```yaml
sound:
  enabled: true
  name: "ENTITY_EXPERIENCE_ORB_PICKUP"
  volume: 1.0
  pitch: 1.0
```

# SocialSpy и CommandSpy

## SocialSpy

```text
/socialspy
/ss
```

Позволяет уполномоченным игрокам видеть личные сообщения других игроков.

## CommandSpy

```text
/commandspy
/cs
```

Позволяет уполномоченным игрокам видеть команды, которые выполняют игроки.

Форматы обоих модулей находятся в `command.yml`. Их можно сделать максимально ненавязчивыми, чтобы сообщения не мешали основному потоку чата.

---

# AFK

Команда:

```text
/afk
```

Игрок может вручную перейти в AFK.

При движении игрок автоматически выходит из AFK и получает уведомление о возвращении в активное состояние.

Обращение к игроку через `/msg` не снимает AFK. Если другой игрок отправляет ЛС AFK-пользователю, отправитель получает уведомление о его статусе.

# Управление чатом

```text
/chat on
/chat off
/chat
```

Также доступны aliases:

```text
/ch on
/ch off
/ch
```

При отключённом чате обычные сообщения блокируются, если игрок не имеет permission для обхода.

```text
primechat.chat.toggle
```

Управление состоянием чата.

```text
primechat.chat.bypass
```

Обход отключения чата.

# Контроль команд

PrimeChat позволяет ограничивать выполнение команд через whitelist, blacklist и задержки.

## Whitelist

Whitelist разрешает только команды, которые указаны в списке:

```yaml
whitelist-enabled: true
whitelist:
  - "msg"
  - "r"
  - "spawn"
```

Если команда отсутствует в whitelist, её выполнение блокируется.

## Blacklist

Blacklist разрешает все команды, кроме перечисленных:

```yaml
blacklist-enabled: true
blacklist:
  - "op"
  - "stop"
```

Whitelist и blacklist предназначены для разных сценариев. Одновременно использовать оба режима без необходимости не рекомендуется.

## Задержки

Задержки можно задавать максимально просто:

```yaml
delays:
  spawn: 5
  home: 10
  warp: 3
```

Значение указывается в секундах.

Permission:

```text
primechat.commanddelay.reduce
```

позволяет использовать уменьшенную задержку, если она настроена.

```text
primechat.commanddelay.bypass
```

полностью отключает задержку для игрока.

```text
primechat.commandcontrol.bypass
```

позволяет обойти ограничения whitelist/blacklist.

# Permissions

| Permission | Назначение | По умолчанию |
|---|---|---|
| `primechat.admin` | Административные функции PrimeChat | OP |
| `primechat.chatcolor` | Цветной и форматированный чат | Нет |
| `primechat.msg` | Личные сообщения | Да |
| `primechat.socialspy` | SocialSpy | OP |
| `primechat.commandspy` | CommandSpy | OP |
| `primechat.clearchat` | Очистка чата | OP |
| `primechat.afk` | Использование AFK | Да |
| `primechat.chat.toggle` | Включение/выключение чата | OP |
| `primechat.chat.bypass` | Обход отключённого чата | OP |
| `primechat.commandcontrol.bypass` | Обход whitelist/blacklist | OP |
| `primechat.commanddelay.reduce` | Уменьшение задержки | Нет |
| `primechat.commanddelay.bypass` | Полный обход задержек | OP |

Permissions пользовательских каналов задаются непосредственно в `config.yml`:

```yaml
permission: "primechat.vip"
```

# Настройка под свой сервер

PrimeChat изначально рассчитан на полную адаптацию под конкретный сервер.

Рекомендуемый порядок настройки:

1. Настройте основные параметры и каналы в `config.yml`.
2. Настройте команды, permissions, сообщения и форматы в `command.yml`.
3. Проверьте локальный и глобальный чат.
4. Проверьте `/msg` и `/r`.
5. Проверьте упоминания и звук.
6. Настройте AFK и управление чатом.
7. При необходимости включите whitelist, blacklist и задержки команд.
8. Выполните `/pc reload`.

Все основные пользовательские сообщения и форматы можно изменить без изменения исходного кода плагина.
